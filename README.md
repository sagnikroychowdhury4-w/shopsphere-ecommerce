# ShopSphere — Synthetic E-Commerce + Reviews API

A deployable demo e-commerce site backed by PostgreSQL and FastAPI. It contains **150,000 synthetic review records** using the same general schema as the supplied reference dataset.

## Features
- Product/review storefront UI
- PostgreSQL database backend
- FastAPI REST API
- `GET /reviews` with pagination, search, rating and sentiment filters
- `GET /reviews/{review_id}`
- `GET /products`
- `GET /stats`
- Swagger/OpenAPI at `/docs`
- Docker + Docker Compose
- Render deployment configuration

## Main API
`GET /reviews?page=1&limit=20`
`GET /reviews?rating=5`
`GET /reviews?sentiment=negative`
`GET /reviews?q=battery`
`GET /reviews/{id}`

## Run locally
1. Install Docker Desktop.
2. From this folder run:
   `docker compose up --build`
3. Open:
   `http://localhost:8000`
4. API:
   `http://localhost:8000/reviews`
5. Swagger:
   `http://localhost:8000/docs`

The first startup seeds PostgreSQL from `data/reviews_150k.csv`.

## Cloud deployment
This repository includes `render.yaml`. Push the folder to GitHub and create a Render Blueprint from that repository. Render will create the web service and PostgreSQL database. Because cloud deployment requires access to your cloud account/GitHub repository, the final public URL is generated by the cloud provider after deployment.

## Dataset
The supplied 300k CSV was used as the schema/reference. This project includes a newly generated 150k synthetic dataset with the same core columns. No real customer identities are intended.
